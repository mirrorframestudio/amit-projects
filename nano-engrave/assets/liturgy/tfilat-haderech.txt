# מה שונה מהנוסח שנמסר, ולמה:
#
#  1. "הִי רָצוֹן"  ←  "יְהִי רָצוֹן"
#     תוקנה טעות הקלדה (חסרה היו״ד).
#
#  2. "(וְתִסְמְכֵנוּ לְשָׁלוֹם)"  ←  בלי סוגריים
#     הוחלט לכלול. הסוגריים בסידור מסמנות תוספת אופציונלית.
#
#  3. "(אם דעתו לחזור מיד אומר וְתַחְזִירֵנוּ לְשָׁלוֹם)"  ←  הושמט
#     זו הוראה מותנית. על תכשיט אין תנאים.
#
#  4. "(לפי נוסח ספרד יי)"  ←  הושמט
#     הערת עורך הסידור, לא נוסח.
#
#  5. ארבעת הפסוקים שבסוף  ←  הושמטו מכאן
#     שלושה מהם כבר נמצאים בשבב במלואם ובניקוד וטעמים מלאים:
#       כי מלאכיו       → בתוך תהילים צ״א
#       ה׳ ישמר צאתך    → בתוך תהילים קכ״א
#       יברכך ה׳        → בתוך ברכת כהנים
#     הרביעי, "ויעקב הלך לדרכו", נוסף לדגם כקטע מקראי נפרד
#     מתוך WLC (בראשית ל״ב, ב׳–ג׳) — כך הוא מנוקד ומוטעם.
#
#  6. "אל"  ←  "אֵל"
#     נוקד. בלי ניקוד הוא נראה כאות מניין ונמחק בעיבוד.
#
#  7. "יי"  ←  "יְהוָה"
#     הוחלט על הצורה המלאה, לאחידות עם הטקסט המקראי שבאותו שבב.
#     הצורה זהה תו-בתו ל-WLC: יו״ד־שווא, ה״א, וי״ו־קמץ, ה״א
#     (בלי טעם — בטקסט ליטורגי אין טעמי מקרא).
#
# *** לתשומת לבך — החתימה ***
# בנוסח שנמסר, החתימה היא "בָּרוּךְ אַתָּה שׁוֹמֵעַ תְּפִלָּה"

יְהִי רָצוֹן מִלְפָנֶיךָ יְהוָה אֱלֹהֵינוּ וֵאלֹהֵי אֲבוֹתֵינוּ,
שֶׁתּוֹלִיכֵנוּ לְשָׁלוֹם וְתַצְעִידֵנוּ לְשָׁלוֹם וְתַדְרִיכֵנוּ לְשָׁלוֹם, וְתִסְמְכֵנוּ לְשָׁלוֹם,
וְתַגִּיעֵנוּ לִמְחוֹז חֶפְצֵנוּ לְחַיִּים וּלְשִׂמְחָה וּלְשָׁלוֹם.
וְתַצִּילֵנוּ מִכַּף כָּל אוֹיֵב וְאוֹרֵב וְלִסְטִים וְחַיּוֹת רָעוֹת בַּדֶּרֶךְ,
וּמִכָּל מִינֵי פֻּרְעָנֻיּוֹת הַמִּתְרַגְּשׁוֹת לָבוֹא לָעוֹלָם,
וְתִתְּנֵנוּ לְחֵן וּלְחֶסֶד וּלְרַחֲמִים בְּעֵינֶיךָ וּבְעֵינֵי כָל רֹאֵינוּ,
כִּי אֵל שׁוֹמֵעַ תְּפִלָּה וְתַחֲנוּן אַתָּה.
