## 1. Google Search Console - הבסיס לכל השאר (15 דקות)

**צריך:** גישה ל-DNS של mikra.shop (איפה שקנית את הדומיין, או Vercel אם הנייםסרברים שם) **או** גישה לוורסל.

**צעדים:**

2. בחר את הסוג השמאלי **"דומיין"** והקלד `mikra.shop` (בלי https). זה מכסה גם www וגם wp.mikra.shop.
3. גוגל מציג רשומת TXT שמתחילה ב-`google-site-verification=`. העתק את כל השורה.
4. אצל רשם הדומיין → ניהול DNS → "הוסף רשומה": סוג `TXT`, שם/Host `@`, ערך = מה שהעתקת, TTL ברירת מחדל → שמור. (אם ה-DNS בוורסל: Vercel → Domains → mikra.shop → DNS Records → Add.)
5. חזור לחלון של גוגל, חכה 2–5 דקות, לחץ **"אמת"**. אם נכשל - חכה עוד עשר דקות ונסה שוב; לא לפתוח נכס חדש.
6. **חלופה בלי DNS:** בחר "קידומת URL" → `https://mikra.shop` → שיטת "תג HTML". גוגל נותן `<meta name="google-site-verification" content="XXXX">`. **האתר כבר יודע להציג את התג הזה** - העתק רק את ה-XXXX שבתוך `content=` → Vercel → הפרויקט → Settings → Environment Variables → שם `NEXT_PUBLIC_GSC_TOKEN`, ערך XXXX → Save → Deployments → Redeploy. או שלח לנו את ה-XXXX ונעשה את זה. אחרי הפריסה לחץ "אמת".
7. אחרי האימות: תפריט שמאלי **"Sitemaps"** → בשדה "הוסף Sitemap חדש" הדבק `https://mikra.shop/sitemap.xml` → "שלח". צריך להופיע "הצלחה" עם ~30 כתובות.
8. **"בדיקת כתובת URL"** (השורה העליונה) → הדבק `https://mikra.shop` → "בקש הוספה לאינדקס". חזור על זה ל-`/blessings` ולשלושה דפי מוצר (`/products/toldot`, `/products/lo-yanum`, `/products/beseter`). לא יותר - יש מכסה יומית.
9. הגדרות → "משתמשים והרשאות" → הוסף את המייל שלנו כ"מלא" כדי שנוכל לראות שגיאות בלי לבקש צילומי מסך.

**מה לא לעשות:** לא להגיש את `feed.xml` כ-Sitemap (זה פיד מוצרים, גוגל ידחה אותו). לא לבקש אינדוקס לכל דף כל יום - זה לא מזרז כלום.
