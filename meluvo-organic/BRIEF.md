# Meluvo — בריף כתיבה למאמר שבועי

קרא את הקובץ הזה במלואו לפני שכותבים. הוא מכיל את כל מה שצריך; אין צורך לחפש באתר.

## המותג בשתי שורות
Meluvo (mymeluvo.com) מוכרת **משקפיים לחסימת אור כחול** ו-**Meluvo Band 3.0** (צמיד מעקב
שינה/התאוששות בלי מסך). המיצוב: "הבחירה של הספורטאים הטובים בישראל" — שחקני ליגת העל,
נבחרת ישראל ומאמני כושר משתמשים במשקפיים כחלק משגרת ההתאוששות.

## למי כותבים (ולמי לא)
- **כן:** ספורטאים ומתאמנים (התאוששות, שינה = ביצועים); מבוגרים מול מסכים עד מאוחר
  (עבודה, גיימינג, טלפון במיטה); מי שמתקשה להירדם או קם עייף; עובדי משמרות.
- **לא:** ילדים / הורים שקונים לילדים. לא לכתוב מאמרי הורות. (הנחיה של אמית, 2026-09-16.)

## סגנון
- עברית מדוברת-מקצועית, גוף שני רבים ("אתם"). בלי סלנג מוגזם, בלי סימני קריאה בכל שורה.
- ישירות: משפט ראשון = הבעיה של הקורא. בלי "בעולם המודרני של היום".
- **ביושר מדעי:** "מחקרים מראים ש…" רק על דברים מבוססים (אור כחול בערב מדכא מלטונין — כן;
  "אור כחול מזיק לרשתית" — לא). כשהראיות מעורבות, לומר את זה.
- אורך: 600–900 מילים. H2 כל 120–180 מילים. H3 בתוך FAQ.
- מבנה קבוע: פתיח (2–3 משפטים) → 3–5 H2 של תוכן → H2 שמחבר למוצר באופן טבעי (לא מכירתי,
  משפט-שניים + קישור) → H2 "שאלות נפוצות" עם 3 H3 → שורת "קראו גם" עם 1–2 מאמרים קיימים.
- טבלה אחת כשיש השוואה. רשימה ממוספרת לטיפים.
- מילת המפתח של הנושא: בכותרת, ב-H2 הראשון, ובפסקה הראשונה. לא לדחוס.
- HTML פשוט בלבד: `<p> <h2> <h3> <ul> <ol> <li> <strong> <em> <table> <a>`. בלי style, בלי class,
  בלי תמונות.

## פלט
1. `meluvo-organic/blog/NN-<handle>.html` — גוף המאמר (HTML בלבד, בלי `<h1>` — הכותרת היא ה-H1).
2. `meluvo-organic/blog/NN-<handle>.json`:
```json
{
  "title": "כותרת עם מילת המפתח, עד 65 תווים",
  "handle": "english-kebab-case",
  "summary": "<p>משפט-שניים לתצוגה בעמוד הבלוג.</p>",
  "description": "meta description לגוגל, 120–155 תווים, כולל מילת המפתח",
  "tags": ["תגית1", "תגית2"]
}
```
3. `python meluvo-organic/publish_article.py meluvo-organic/blog/NN-<handle>.json` — מפרסם.
4. עדכון `TOPICS.md`: הנושא עובר מ"בתור" ל"פורסם" עם תאריך ו-handle.
