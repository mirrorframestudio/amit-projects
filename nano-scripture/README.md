# מִקְרָא · MIKRA

חנות תכשיטי ננו. כל תכשיט נושא שבב סיליקון שעליו נצרבת **ברכה שלמה** —
מילה במילה, בלי קיצור. חמישה נוסחים לבחירה.

עברית, RTL מלא. Next.js 16 + TypeScript + Tailwind 4.

```bash
npm install
npm run dev     # http://localhost:3200
npm run build
```

## המותג

**מִקְרָא · MIKRA**, נבחר מתוך שלוש הצעות. אוֹת וסיליקה נשמרות בהיסטוריית
הגיט ולא בקוד החי.

הזהות ב־[lib/brand.ts](lib/brand.ts); הפלטה, הטיפוגרפיה והרדיוסים ב־`:root`
של [app/globals.css](app/globals.css) — ערכה אחת, בלי מתג ובלי `data-brand`.
כל האתר ב־Heebo, גופן יחיד.

מִקְרָא הוא השם העברי לכתבי הקודש, מלשון קריאה. בלטינית הוא נקרא MIKRA
וטומן בתוכו את MICRO.

## שני הצירים של הקטלוג

**ברכות** — [lib/blessings.ts](lib/blessings.ts). חמישה נוסחים, **מיוצרים
אוטומטית מקובצי ה־docx המקוריים** (הסקריפט בהיסטוריה). הטקסטים, ספירת המילים
וספירת התווים הם האמיתיים, לא מוערכים.

**קטגוריות** — שרשראות · צמידים · סיכות · טבעות. קטגוריה בלי דגמים נעלמת
לבד מהניווט ומהפוטר דרך `ACTIVE_CATEGORIES`; הטבעות עוד לא הוזמנו, ולכן
אינן מופיעות.

לכל מוצר יש `blessings: BlessingId[]` — הנוסחים שאפשר לצרוב עליו, לפי קובץ
ההתאמה של הספק. הבחירה נעשית בעמוד המוצר, והעגלה מפתחת לפי תכשיט + ברכה,
כך שאותו דגם עם שני נוסחים הוא שתי שורות.

## הנתונים אמיתיים

הקטלוג ב־[lib/catalog.ts](lib/catalog.ts) בנוי מ־PI של YIYA Jewelry
(`JW-20260803-1`): מק״טים, מידות, חומרים ועלויות כפי שהם בהזמנה. 16 מק״טים
בפלדת אל־חלד 316L ובכסף 925 — **לא זהב 14K**, ואסור שהאתר יטען אחרת.

הפריט היחיד שאינו משם הוא סיכת התינוק (`BABYPIN01`); המק״ט והעלות שלה
ממתינים לספק, ולכן `cost` אופציונלי.

## תמונות המוצר

צילומי הספק הגיעו כחיתוכים על רקע לבן. `public/products/*.png` הם אותם
צילומים אחרי **הסרת רקע** — מילוי הצפה מהשוליים ולא סף גלובלי, כך שהלבן
*בתוך* התכשיט (השתקפויות, זירקוניה, החלל של עץ החיים) נשאר.

התוצאה: התכשיט יושב על כל רקע, ואין ריבוע לבן שצף בתוך אריח. אל תחזירו
`mix-blend-mode: multiply` — הוא מיותר עכשיו ורק מאפיר את המתכת.

## מלכודות שכבר נפלנו בהן

**אסור `h-1` / `h-2` / `h-3` לכותרות.** אלה מחלקות גובה של Tailwind
(`height: .25rem`) שמכווצות את הכותרת לארבעה פיקסלים וגורמות לה לדרוס את
כל מה שמתחתיה. מחלקות הכותרות כאן הן `t-hero` / `t-1` / `t-2` / `t-3`.

**`overflow-x: clip` ולא `hidden`.** `hidden` על `body` הופך אותו למיכל
גלילה, שובר `position: sticky` ומאפס מדידות גלילה.

**הכתב הזעיר הוא canvas, לא DOM.** `lib/nanoText.ts` פורס את הנוסח לשורות
שממלאות בדיוק את המלבן, והעדשה מציירת מחדש רק את השורות והתווים שבתוך
המעגל — כ־0.005ms לפריים. הגרסה הראשונה החזיקה עשרות אלפי תווים ב־DOM
והגדילה אותם ב־`transform`; זה השאיר חצי מהלוח ריק וגם תקע את הדפדפן.

**הכותרת אטומה בכוונה.** שקיפות גורמת לכל אזור כהה מתחתיה להציץ ולצבוע
חצי מהסרגל באפור.

**RevealEngine סורק גם בטעינה.** בלי זה, רענון עם שחזור מיקום גלילה או
כניסה דרך עוגן משאירים את כל מה שמעל המסך שקוף לצמיתות.
