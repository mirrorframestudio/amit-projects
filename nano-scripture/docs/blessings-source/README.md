# נוסחי הברכות — קבצי המקור

חמשת הנוסחים כפי שנמסרו, ומסמך הריכוז שהוכן לרב.

**אלה המקור. `lib/blessings.ts` הוא הנגזרת.**

הקוד באתר עבר עיבוד: טעמי המקרא מוסרים לתצוגה ולצריבה כאחד (ראו
`lib/scripture.ts`), הטקסט מחולק למבנה של קוד, והעימוד המקורי אינו
נשמר. כל בדיקה מול רב, כל שינוי נוסח וכל ספק לגבי מה באמת כתוב —
מתחילים מהקבצים כאן ולא מהקוד.

## מבנה הקבצים

בכל קובץ הפסקה הראשונה היא **כותרת הברכה**, ואחריה — בארבעה מתוך
החמישה — **שורת המקורות**. שתיהן מטא־דאטה ואינן נצרבות. הגוף מתחיל
מהפסקה שאחריהן.

בברכת התינוק אין שורת מקורות, והפסקה השנייה כבר שייכת לנוסח.

הספירות הן של הגוף בלבד, אחרי הסרת טעמי מקרא — כלומר של הטקסט שנצרב
בפועל. הן מאומתות תו־בתו מול `lib/blessings.ts`.

## שים לב

`מִקְרָא — נוסחי הברכות לרב.docx` הוכן מהנוסחים **הקודמים**, לפני
התיקון של אוגוסט 2026. הוא אינו משקף את הנוסחים שכאן, ויש להפיק אותו
מחדש לפני התייעצות נוספת.
